## Introduction

When I decided to build my portfolio, I had several options: vanilla React, Gatsby, or even plain HTML/CSS. But I chose **Next.js** - and here's why.

As a full-stack developer who works primarily with React, I wanted a framework that would:

1. Showcase my skills effectively
2. Provide excellent performance
3. Make content management easy
4. Support future growth (like adding a blog)

Next.js checked all these boxes and more.

---

## Why Next.js?

### 1. Performance Out of the Box

Next.js offers **Server-Side Rendering (SSR)** and **Static Site Generation (SSG)** which means pages load faster, better SEO rankings, and improved user experience.

For a portfolio, this is crucial - recruiters and hiring managers don't wait for slow sites.

### 2. File-Based Routing

One of my favorite features is the file-based routing system. Pages like `index.tsx` become `/`, `blog/[slug].tsx` becomes `/blog/why-nextjs`.

This made organizing my portfolio clean and intuitive.

### 3. Built-in Image Optimization

The `next/image` component automatically optimizes images for different screen sizes, converts to modern formats like WebP and AVIF, and lazy loads images offscreen.

This was a game-changer for maintaining fast load times.

### 4. API Routes

Next.js API routes allowed me to handle contact form submissions, serve dynamic content, and build a full-stack portfolio without a separate server.

### 5. Excellent Developer Experience

Hot Reload for instant feedback, TypeScript support built-in, and zero config deployment to Vercel.

---

## What I Learned

### 1. Hybrid Rendering is Powerful

Using the `use client` directive strategically helped me keep most pages as server components for better performance, and add interactivity only where needed.

### 2. Tailwind CSS + Next.js = Match Made in Heaven

The combination of Tailwind's utility classes and Next.js's component architecture made styling a breeze.

### 3. SEO is Built-in

Next.js handles metadata, OpenGraph, and sitemaps automatically - perfect for getting discovered.
