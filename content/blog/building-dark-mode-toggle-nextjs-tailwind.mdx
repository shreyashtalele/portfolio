## Introduction

Dark mode has become a standard feature in modern web applications. It's not just trendy - it reduces eye strain and saves battery life on OLED screens.

In this post, I'll show you how I implemented dark mode in my portfolio using Next.js and Tailwind CSS with system preference detection, manual toggle with sun/moon icons, persistence across page reloads, and smooth transitions.

---

## Step 1: Set Up Tailwind for Dark Mode

First, update tailwind.config.js to enable class-based dark mode.

Then add CSS variables in globals.css for both light and dark themes.

---

## Step 2: Create Theme Hook

Create a useTheme hook that:

- Detects system preference on first visit
- Checks localStorage for saved preference
- Toggles between light and dark
- Persists the preference

---

## Step 3: Create Theme Toggle Button

Create a client component that:

- Uses the useTheme hook
- Shows sun icon for dark mode
- Shows moon icon for light mode
- Toggles theme on click

---

## Step 4: Add Smooth Transitions

Add CSS transitions for background-color, border-color, and color to make theme switching smooth.

---

## Step 5: Test Your Implementation

- First visit: Follows system preference
- Click toggle: Switches theme
- Reload page: Theme persists
- Inspect HTML: dark class toggles

---

## Conclusion

Dark mode is surprisingly easy to implement with Next.js and Tailwind CSS. The key takeaways are using class-based dark mode, storing preference in localStorage, detecting system preference as fallback, and adding smooth transitions for polish.
