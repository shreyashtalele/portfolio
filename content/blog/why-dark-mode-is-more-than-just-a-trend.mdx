## Introduction

Dark mode has become a standard feature in most applications. But when I first added it to my portfolio, I asked myself: is this really worth the effort?

After implementing it, I realized it's not just about trends.

Dark mode has real benefits for users.

---

## Why Dark Mode Matters

### 1. Reduced Eye Strain

Staring at bright white screens for hours is tiring. Dark mode reduces the amount of blue light emitted, which can help reduce eye strain — especially in low-light environments.

I work late at night. Dark mode is genuinely more comfortable.

### 2. Better Battery Life

On OLED screens, dark pixels use less power than bright pixels.

It's not a huge difference, but it adds up. For users who spend hours on their devices, dark mode can save battery life.

### 3. Accessibility

Some users are sensitive to bright light. Others have visual impairments that make high-contrast interfaces more comfortable.

Dark mode gives them an option.

### 4. Focus and Productivity

I've found that dark mode helps me focus. The reduced brightness means fewer distractions. Less visual noise.

---

## How I Implemented Dark Mode in My Portfolio

I used Tailwind's class-based dark mode with CSS variables.

The setup was straightforward:

1. Add `darkMode: "class"` to `tailwind.config.js`
2. Use CSS variables for colors
3. Create a theme toggle component
4. Use `localStorage` for persistence

It took a few hours to set up properly. But it was worth it.

---

## The UX Considerations

Dark mode isn't just about colors. It's about usability.

I made sure to:

- **Maintain contrast ratios** — Text should be readable
- **Keep consistent borders** — Visual hierarchy should stay intact
- **Support smooth transitions** — Switching themes shouldn't be jarring
- **Respect system preferences** — Users shouldn't have to manually toggle if they don't want to

---

## The Result

Users can now switch between light and dark mode based on their preference. The toggle persists across page reloads.

It's a small feature. But it makes the experience better.

---

## Conclusion

Dark mode isn't just a design trend. It's a practical feature that improves user experience, accessibility, and battery life.

If you haven't added it to your application, I'd recommend doing so. Your users will appreciate it.
